# DarSak 0.1.0

DarSak is an Arabic/English teaching platform for organizing teacher profiles, learning groups, enrollment review, lesson schedules, resource links, and group assignments with private teacher feedback.

## Open-source foundation

- MIT licensing for original project code and documentation, with bundled font notices preserved.
- Reliable booking tests with a fixed clock, so fixture dates no longer expire in CI.
- Contributor and security guides, issue/PR templates, and a public maintenance roadmap.
- Fresh-clone setup instructions, independently owned hosted-backend guidance, and an opt-in synthetic local demo.
- Published starter issues for independent setup, translation, and accessibility work.
- A pilot/evidence guide that supports aggregate university feedback without publishing participant names.

## Setup and validation

Start with [Development](https://github.com/abdulrahman-111/DarSak/blob/v0.1.0/docs/DEVELOPMENT.md). For your own hosted backend, see [Deployment](https://github.com/abdulrahman-111/DarSak/blob/v0.1.0/docs/DEPLOYMENT.md). Keep the public-password demo local and disposable.

Validation includes 731 unit tests, formatting, lint, typechecking, production builds, fresh migrations, pgTAP contracts, all 56 database fixtures, and synthetic role/access smoke checks. A separate fresh app clone and backend were also used for Arabic/English browser sign-in, teacher groups, student dashboards/timetables, discovery, and anonymous-route protection. See the [validation record](https://github.com/abdulrahman-111/DarSak/blob/v0.1.0/docs/releases/0.1.0-validation.md) for environment details, evidence, and exclusions.

## Known limitations

- This is an initial public release, not a security audit or a guarantee of support response times.
- Scheduling uses Africa/Cairo time; arbitrary scheduling time zones are not available.
- The launch policy accepts new lesson resources as links and disables new binary, avatar, cover, and CV uploads; existing objects can remain readable where permissions allow.
- Independently owned hosted-backend instructions are provided. A deployment performed by an outside developer and fully self-managed production Supabase hosting have not been verified as part of this release.
- Email configuration/delivery, optional Google sign-in, Turnstile, notification email, and destructive account-deletion workers were excluded from this release walkthrough. Their existing operator requirements and limitations remain documented in the deployment guide.
- The local demo has known public credentials. Never load it on a hosted instance or expose the local stack publicly.
- The maintainer reports teacher/student use at their university. Aggregate counts, dates, repeat usage, and feedback are not yet substantiated in the public evidence record. Automated tests and screenshots do not establish independent adoption.
