# Attendance release

Lessons now have a paginated accepted-student register with Present/Absent/Late/Excused/Clear. Approved active owners mark attendance after lesson start; future/cancelled/archived lessons remain read-only. Owners and admins review history; active accepted students see only their own result. Unmarked is distinct from absent. Writes serialize group→lesson→enrollment, recheck approval after waiting, and record identity/time on the server. No raw authenticated writes.

The admin denial regression was added after independent Sol review and passes.
