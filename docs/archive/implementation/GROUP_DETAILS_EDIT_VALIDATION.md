# Published group editing and Arabic labels

Teachers can open Edit details on an owned published group to change its name, description, subject/year or student category, capacity, and location. The existing details form and atomic RPC are reused. Existing ownership, active teacher access, catalogue ownership and optimistic concurrency checks remain; published groups additionally require teacher approval. Capacity cannot be reduced below accepted enrollment count, serialized by the same group lock used for enrollment approval. Publication status, enrollments, weekly schedule and lessons are preserved. Archived groups remain read-only.

Arabic/English catalogue labels now fall back to the available language in group setup choices, teacher group cards and public specialization labels. Arabic-only catalogue labels and shared Unicode group names were saved successfully through real browser forms before the change; the English group card then failed to show the Arabic-only subject. That display regression is fixed. Group names remain one teacher-entered name; automatic translation is not added. Text inputs use automatic direction.
