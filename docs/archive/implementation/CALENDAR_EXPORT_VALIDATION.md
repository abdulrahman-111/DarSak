# Private calendar export

Teachers download their own dated lessons; students download only accepted-group lessons. Cairo date ranges are inclusive, limited to93days/500events, and retain cancelled/historical lessons. UTC calendar dates, stable UIDs, escaped text and75-octet UTF8 folding produce a private ICS download. Headers prevent caching. Forms support English/Arabic, inline errors, and explain that this is a dated-lesson download rather than a live subscription.

Luna implemented; Sol approved specification/security/code review. Checks passed:312units/49files,31SQL suites,173 existing API assertions, zero-warning lint/typecheck, local webpack build andfive local API/browser bundles including actual EN/AR downloads for teacher/student, Cairo midnight boundary, Arabic content, cancelled status, private-group omission, and anonymous/invalid-range no-store responses. Fixtures were corrected for the real schema and the Cairo DST midnight gap. A stale attendance fixture was removed only from local test data and cleanup strengthened. The calendar harness initially counted a literal escaped title as an extra event; anchored event-line counting corrected the assertion. A transient download wait timed out once; the subsequent full bilingual run passed with all export requests HTTP200. No production fixtures were created.
