# Supabase contract v1

All IDs uuid default gen_random_uuid unless indicated. All rows have created_at timestamptz default now(). Schema public. RLS for every table. Active means profiles.status='active'. User roles student/teacher/admin, status active/suspended; teachers additionally teacher_profiles.approved. Public exposure must use safe teacher fields only.

Tables:
- profiles: id references auth.users, full_name text, role text, status text, preferred_language ar/en default ar. Private, users read own; group owners may read enrolled students' names via safe RPC/view (never full private profiles). Admin controls role/status.
- teacher_profiles: id references profiles, bio text, headline text, avatar_path text nullable, approved boolean default false. Public approved active teachers only. Owner edit bio/headline, not approved.
- student_profiles: id references profiles, offering_id uuid nullable references offerings.
- education_nodes: id, parent_id nullable self reference, kind text in system/level/grade/university/faculty/department/year, name_ar, name_en, slug unique. Hierarchy for academic catalogue.
- subjects: id, name_ar, name_en, slug unique.
- offerings: id, node_id references education_nodes, subject_id references subjects, unique pair. School grade, university year or general university node defines context.
- teacher_specializations: teacher_id, offering_id, composite PK.
- teacher_contacts: teacher_id PK references teacher_profiles, phone_number and whatsapp_number nullable E.164 (`+` plus 8–15 digits), contact_email nullable up to 254 characters, visibility `enrolled` by default or `public`. Optional blanks normalize to NULL. Kept separate from login email. RLS exposes contacts only to the active owner/admin, approved active teacher's explicit public audience, or an active student with a currently accepted enrollment in one of the teacher's groups. Public policy uses the narrowly granted `can_read_teacher_contacts(p_teacher_id uuid)` helper; raw Data API reads are protected too.
- teacher_profiles.avatar_path is NULL or an own-teacher UUID prefix followed by a random UUID filename with `.jpg`, `.png`, or `.webp`. The separate `teacher-avatars` bucket is private, capped at 2 MiB, and accepts JPEG/PNG/WebP only. `can_read_teacher_avatar(p_name text)` allows an active owner/admin or the currently referenced avatar of an approved active teacher; an unreferenced image stays private to its active owner. Owners can delete their own valid-path objects for upload compensation. No avatar policy changes apply to lesson materials.
- group_lesson_exclusions: `(group_id,local_date)` primary key with cascading group foreign key. Owner/admin can read; direct writes are denied and `set_lesson_exclusions` atomically replaces at most 366 distinct dates (empty array clears all dates).
- groups: id, teacher_id profiles, offering_id, name text, description text default '', capacity integer 1..500, status draft/published/archived, location text default '', created_at.
- group_schedule_slots: id, group_id, weekday integer 0..6 (Sunday=0), start_time time, end_time time, timezone text default Africa/Cairo. Same-day only. Teacher overlap prevention required.
- enrollments: id, group_id, student_id, status pending/accepted/rejected/cancelled/removed, unique(group_id,student_id), updated_at.
- lessons: id, group_id, slot_id nullable group_schedule_slots, title text, starts_at timestamptz, ends_at timestamptz, status scheduled/cancelled/completed, notes text default ''. Actual occurrences; accepted membership required to read. Owner manages. Prevent teacher overlaps including across groups.
- lesson_materials: id, lesson_id, kind file/link/note, title, storage_path nullable, url nullable, content nullable, file_size bigint nullable, mime_type nullable, uploaded_by profiles.
- notifications: id, user_id profiles, kind text, title_ar text, title_en text, href text nullable (app-relative), read_at nullable.
- reports: id, reporter_id profiles, subject text, description text, status open/resolved, admin_note text default ''. Own create/read; admin handles.
- platform_settings: key text PK, value jsonb. Admin only except explicit public safe settings if needed.

RPCs (server actions call with authenticated supabase client):
- save_teacher_profile(p_full_name text,p_headline text,p_bio text,p_offering_ids uuid[],p_phone_number text,p_whatsapp_number text,p_contact_email text,p_visibility text) returns void. Authenticated active teacher only; atomically updates their own profile name, headline, bio, specializations, and contact row. Name 2–100, headline at most 160, bio at most 5000, distinct valid offering IDs, validated contact formats and visibility. Does not change role, account status, approval or Auth email.
- request_enrollment(p_group_id uuid) returns uuid. Student only; published group; allow new or rejected/cancelled/removed retry -> pending; accepted/pending unchanged or error.
- decide_enrollment(p_enrollment_id uuid,p_status text) returns void. Owner/admin only pending->accepted/rejected; accepted->removed; capacity atomic, notifications created.
- cancel_enrollment(p_enrollment_id uuid) returns void. Student owns pending/accepted -> cancelled.
- save_schedule_slot(p_group_id uuid,p_weekday int,p_start_time time,p_end_time time,p_slot_id uuid default null) returns uuid. Acquires the teacher-calendar advisory lock before group/slot row locks, then rechecks ownership and conflict conditions. Edits cannot silently corrupt existing dated lessons.
- delete_schedule_slot(p_group_id uuid,p_slot_id uuid) returns void. Owner/admin only; takes the same teacher-calendar advisory lock before group then slot row locks and rechecks ownership after locking. Slot must belong to the supplied group and have no dated lesson reference (including cancelled or completed lessons). A published group must retain one schedule slot; a draft group may remove its last slot. Direct authenticated slot deletes remain denied.
- publish_group(p_group_id uuid,p_from date default null,p_until date default null) returns integer. Owner/admin only; takes the teacher-calendar lock before the group row lock, then rechecks authorization, active approved teacher, valid group details and at least one saved slot. Both generation dates must be supplied together; when provided, generated lessons and publication commit atomically. Direct inserts/transitions to published are guarded and must use this RPC.
- duplicate_group(p_group_id uuid) returns uuid. Owner/admin only; takes the source teacher-calendar lock before the source group row lock and rechecks authorization and active source teacher. Creates a draft for the source teacher with its offering, bounded copy-suffixed name, description, capacity and location; memberships, history, exclusions, materials and schedule slots are never copied. Authenticated callers only; service-role execution is revoked.
- create_lesson(p_group_id uuid,p_title text,p_starts_at timestamptz,p_ends_at timestamptz,p_notes text default '',p_lesson_id uuid default null) returns uuid. Acquires the teacher-calendar lock before group/lesson row locks, then rechecks owner/admin and conflicts. Updating a generated lesson preserves its original `slot_id` and `local_date`; manual lesson dates follow the new start time.
- set_lesson_status(p_lesson_id uuid,p_status text) returns void. Owner/admin only; acquires the teacher-calendar lock before group/lesson row locks. Activating as scheduled or completed rejects dated overlaps; cancellation uses the same lock.
- set_lesson_exclusions(p_group_id uuid,p_dates date[]) returns void. Owner/admin only; atomically replaces at most 366 distinct finite, non-NULL saved dates under the teacher-calendar lock. Empty array explicitly clears saved exclusions.
- generate_lessons(p_group_id uuid,p_from date,p_until date) returns integer. Finite inclusive range at most 90 days; recomputes shared candidates under the teacher-calendar lock, honors exclusions, rejects missing/ambiguous Cairo local times and any conflict, and rolls back the whole batch on failure. Occurrence identity remains group/slot/local date; existing cancelled/completed occurrences are not recreated.
- preview_lesson_generation(p_group_id uuid,p_from date,p_until date) returns `(slot_id,local_date,start_time,end_time,starts_at,ends_at,state,conflict_lesson_id,conflict_group_id,conflict_title)` where state is ready/already_generated/excluded/conflicting. Owner/admin only and read-only; rejects null/reversed/>90-day ranges and missing or ambiguous Cairo wall times. Existing occurrence identity takes precedence and preserves stored timestamps; excluded rows may have null timestamps.
- admin_update_user(p_user_id uuid,p_status text,p_approved boolean default null) returns void. Admin only, updates status and teacher approval; no public role granting.
- group_students(p_group_id uuid) returns table(enrollment_id uuid,student_id uuid,full_name text,status text). Owner/admin only.
- public_teachers() returns table(id uuid,full_name text,headline text,bio text,avatar_path text). Approved active only.
- public_teacher_specializations(p_teacher_id uuid) returns table(offering_id uuid). Approved active only; narrow public projection that leaves `teacher_specializations` direct reads and writes under their existing owner/admin policy.
- public_groups() returns published group fields plus approved active teacher name, bilingual subject/context names, accepted_count, and available_seats. Safe for anonymous discovery; it never returns private profiles or roster identities.

Auth trigger creates profile from full_name and requested_role metadata, only student/teacher permitted, never admin. Never authorize via editable metadata. Teacher remains unapproved until operator/admin review. `bootstrap-admin` operator script uses service key only outside application runtime. User cannot alter profile.role/status or teacher.approved through direct UPDATE.

Storage bucket `lesson-materials`, private, 10 MB cap PDF/JPEG/PNG/WebP. Object path `${teacherId}/${lessonId}/${randomUuid}.${extension}`. Metadata insert must match path ownership and lesson owner. Accepted students may read only when corresponding lesson_materials row exists. Teacher owner/admin manage; suspended denied. Profile picture upload can be deferred to a safe configured avatar URL/path field, but do not expose arbitrary storage.

Security hardening: accepted membership requires an active student profile on every protected read, including Storage. Recurring schedule writes go through `save_schedule_slot`; direct authenticated slot writes are revoked. Slot and lesson update IDs must already belong to the supplied group, and a lesson's recurring slot must belong to that same group. Initial file upload is authorized from the opaque teacher/lesson object path before metadata exists; later reads, replacement, and deletion require the metadata relation. File cleanup after metadata failure remains an application responsibility. Link and note metadata has no storage path. Catalogue and platform-setting mutations require an active administrator through RLS.

Occurrence preview internals live in the unexposed `dars_private` schema. `dars_private.cairo_local_instant(p_local_date date,p_local_time time) returns timestamptz` samples Cairo offsets around the wall time and accepts exactly one round-tripping UTC instant. The shared Task 4 candidate interface is `dars_private.lesson_generation_candidates(p_group_id uuid,p_from date,p_until date)` returning the same occurrence/conflict columns as the preview RPC. It checks saved exclusions and occurrence identity before conversion, then performs null-safe overlap checks against active dated lessons across all groups owned by the teacher. Anon/authenticated receive no private schema usage or direct function execution.

Public queries: education_nodes,subjects,offerings; groups published + approved active teacher. Teacher full name via public_teachers RPC, not profiles. Owner can read draft groups. Accepted students can read their group's content even if unpublished (archived remains historical read).

Application routes locale-prefixed: /[locale], /teachers, /teachers/[id], /classes, /classes/[id], /login, /register, /dashboard, /profile, /timetable, /notifications, /reports, /teacher/groups, /teacher/groups/[id], /teacher/requests, /teacher/students, /teacher/lessons, /student/classes, /student/materials, /admin, /admin/users, /admin/education, /admin/groups, /admin/reports, /admin/settings.
