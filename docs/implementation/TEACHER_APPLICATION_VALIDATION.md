# Required teacher applications

Extend the existing teacher profile and review flow with a private application checklist, PDF CV, teaching years, administrative phone, optional supporting links and declaration of accuracy/permission to share. Reuse rich profile experience, qualifications, languages, approach and subject/student-level selections. Incomplete drafts may be saved; submission captures and validates the same immutable snapshot. Admins approve, decline or request changes with feedback. Existing approved accounts retain approval without a new mandatory application.

New active-owner/admin-only table and RPCs reject direct mutations, foreign document attachment, stale saves and incomplete submission. Canonical admin approval, compatibility paths and direct approval changes reject unsubmitted new applications. Private PDF storage limits uploads to 5 MiB, random owned paths and authenticated owner/admin downloads. Signed downloads expire after 60 seconds and use attachments. Authenticated overwrite and deletion are disabled; deletion policy checks could otherwise race submission. Application information never enters public projections. Pending or expired teachers can open application/profile preparation without enabling teaching permissions.
