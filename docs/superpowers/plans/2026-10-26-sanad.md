# Sanad Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Connect a useful bilingual staging AI assistant and teacher drafting preview.

**Architecture:** Bounded server-only Gemini REST endpoint, private atomic quota reservation, and existing accessible assistant drawer/form. No agent tools or production rollout.

**Tech Stack:** Next.js, React, TypeScript, Zod, Supabase PostgreSQL, built-in fetch, Gemini generateContent.

**Spec:** ../specs/2026-10-26-sanad-design.md

## Global Constraints

- Exact staging backend and adult tester allowlist; no main merge.
- No private records/model tools, prompt storage, raw provider errors or public secrets.
- Keep English/Arabic, mobile, authorization and ordinary save/publish unchanged.
- Fixed model, 20-second timeout, 24 KiB input, 64 KiB provider response and bounded validated output.

## Review Focus

- Forged browser role or unknown tester cannot cause inference.
- Empty/missing configuration fails closed without disrupting normal dashboard use.
- Concurrent requests share persistent limits and failure attempts stay charged.
- Aborted/closed UI does not apply stale drafts or render model HTML.
- Four-field apply preserves other fields and optimistic concurrency tokens.
