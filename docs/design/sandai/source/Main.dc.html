How it behaves

Lives in the corner

Docked at the bottom end corner (left in Arabic), above the mobile tab bar. Drag to the other side. Never covers primary buttons or form fields.

Speaks only when useful

One bubble at a time, at most one unprompted tip per page. Bubbles fade after 8 seconds and never appear while you are typing.

Shows real state

Thinking only while a request runs. Needs you only when an answer or confirmation is required. Done and Oops always say what happened.

Respects focus

Hide with one click; sleeps after 2 minutes. Reduced motion turns off all bobbing. Screen readers hear state changes in a polite live region.
